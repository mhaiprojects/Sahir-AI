## New machine — one command setup

```bash
git clone git@github.com:mhaiprojects/MH-VoiceAssistant-A.git
cd MH-VoiceAssistant-A

bash setup.sh native    # Arch/Manjaro: venv + Ollama + Piper + TLS
# or
bash setup.sh docker    # Docker Compose (Ollama + web)
```

### Setup scripts

| Script | Purpose |
|--------|---------|
| `setup.sh` | Orchestrates secrets, certs, install or Docker |
| `scripts/generate_secrets.sh` | Copy `.env.example` or `.env.docker.example` → `.env` |
| `scripts/generate_web_cert.sh` | Self-signed TLS + update `.env` paths |
| `scripts/install.sh` | Arch packages, Ollama, venv, pip, Piper download |
| `scripts/setup_models.sh` | Download Piper ONNX from HuggingFace |
| `scripts/docker-up.sh` | Wrapper: `setup.sh docker` |

### Regenerate secrets/certs

```bash
FORCE=1 bash scripts/generate_secrets.sh native   # or docker
FORCE=1 bash scripts/generate_web_cert.sh
```

### LAN IP in certificate

```bash
WEB_CERT_SAN='DNS:localhost,IP:127.0.0.1,IP:192.0.2.10' bash setup.sh docker
```

## Docker Compose files

| File | Purpose |
|------|---------|
| `docker-compose.yml` | voice-assistant + ollama |
| `docker-compose.gpu.yml` | NVIDIA GPU for Ollama + Whisper |
| `docker-compose.cursor.yml` | Mount host `cursor-agent` + workspace |
| `Dockerfile` | Web image (Python 3.12, ffmpeg, Piper preload optional) |
| `docker/entrypoint.sh` | Wait Ollama, pull model, certs, Piper |

Build args: `PRELOAD_WHISPER`, `PRELOAD_PIPER`

Full details: [DOCKER.md](../DOCKER.md)

## Native vs Docker

| Capability | Native | Docker |
|------------|--------|--------|
| Web UI + LAN mic | Yes | Yes |
| Ollama | Host install | Sidecar container |
| PTT / wake word | Yes | No (disabled) |
| PC control | Yes | No (unless host tools mounted) |
| Cursor CLI | Host PATH | Optional compose override |

## Environment templates
